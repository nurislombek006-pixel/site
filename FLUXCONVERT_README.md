# FluxConvert — конвертер файлов

Самостоятельный веб-сайт для конвертации файлов с русскоязычным адаптивным интерфейсом, сервером FastAPI и движками LibreOffice, FFmpeg, Pillow и PyMuPDF.

## Что работает

- **Изображения:** JPG/JPEG, PNG, WEBP, BMP, GIF, TIFF, ICO → PNG, JPG, WEBP, BMP, GIF, TIFF, PDF (по доступным парам). JPG/PNG/WEBP друг в друга конвертируются в браузере без отправки на сервер.
- **Документы:** DOC, DOCX, ODT, RTF, TXT → PDF и совместимые документные форматы, включая Word → PDF.
- **PDF:** → DOCX (через `pdf2docx`), TXT или JPG/PNG (ZIP с изображениями всех страниц).
- **Презентации:** PPT, PPTX, ODP → PDF и совместимые презентационные форматы.
- **Таблицы:** XLS, XLSX, ODS, CSV → PDF и совместимые табличные форматы.
- **Аудио:** MP3, WAV, OGG, FLAC, M4A, AAC, WMA → MP3, WAV, OGG, FLAC, M4A, AAC.
- **Видео:** MP4, MOV, MKV, WEBM, AVI → MP4, WEBM, MKV, а также извлечение звука в MP3, WAV, M4A.

Список вариантов приходит с `GET /api/formats` и в интерфейсе зависит от расширения загруженного файла. Из-за ограничений форматов далеко не все произвольные комбинации технически осмысленны.

**Ограничения:** GIF и TIFF обрабатываются как отдельное изображение (для анимации берётся один кадр). PDF → DOCX приблизительно восстанавливает верстку, не выполняет OCR для сканов; таблицы и сложные объекты могут сместиться. PDF → JPG/PNG отдаёт ZIP. При экспорте электронных таблиц в PDF слишком узкие исходные столбцы могут обрезать текст. Для конвертации видео нужны время и ресурсы CPU. При конвертации через LibreOffice шрифты могут быть заменены, если исходных нет на сервере.

## Самый простой запуск — Docker

Установите Docker Desktop, в папке проекта выполните:

```powershell
docker compose up --build -d
```

Откройте **http://localhost:8000**.

Для остановки: `docker compose down`. Backend и сайт размещены на одном адресе, поэтому не требуется настройка CORS или отдельного frontend.

## Разработка без Docker

Требуются Python 3.11, LibreOffice, FFmpeg (программы доступны в PATH):

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

В macOS/Linux вместо активации PowerShell используйте `source .venv/bin/activate`.

Без сервера можно открыть `static/index.html` — **JPG/PNG/WEBP → JPG/PNG/WEBP** заработает локально в браузере. Для документов, PDF, аудио и видео нужен работающий сервер.

## Публикация на сайте

Для первой версии разместите **весь Docker-контейнер** на сервере/VPS с выделенными CPU и RAM и укажите ему домен через HTTPS-прокси (например, Cloudflare DNS + reverse proxy). Обычный статический GitHub Pages, Cloudflare Pages или простой Worker без отдельного сервиса не запустит LibreOffice/FFmpeg. Можно позже отделить интерфейс (Pages) и API (свой сервер) с корректной настройкой CORS/проксирования.

В проекте нет автоматической публикации, домен не подключён, и публичный production-сервис ещё **не готов** по безопасности. Это тестируемый прототип для собственного сервера.

## Что добавить перед публичным открытием для всех

1. Очередь конвертаций и ограничение одновременных запросов; rate limiting и Turnstile/антибот-меры.
2. Изоляцию обработки недоверенных файлов от доступных сервисов и сети; контейнерная или отдельная sandbox-инфраструктура (одного Docker `no-new-privileges` недостаточно).
3. Антивирус/проверку файлов, контроль распаковки, ограничения памяти/CPU/диска и безопасную очистку после аварий.
4. Вход, учет тарифов и учёт потреблённых ресурсов, мониторинг, логи без содержимого файлов и политику приватности.
5. Очередь фоновой обработки, прогресс конвертации по задачам, поддержку OCR, дополнительные форматы, крупные файлы и более точный рендеринг.

## API

- `GET /api/health` — проверка состояния.
- `GET /api/formats` — поддерживаемые исходные и целевые расширения.
- `POST /api/convert` — `multipart/form-data`: `file` и поле `target` (например, `pdf`). Ответ — конвертированный файл.

По умолчанию: максимум 80 МБ входящего файла, 160 МБ результата, 60 страниц PDF, 120 секунд на внешнюю программу. Меняется переменными окружения в Docker Compose.

Файлы сохраняются во временную рабочую папку и удаляются после скачивания; для повреждённых файлов удаляются при ошибке. На продакшне стоит добавить periodic cleanup на случай принудительного завершения процесса.
